Instructions for creating an avatar
In the code, locate the following lines:
generator.generate("Desired Name 1", "avatars/test1.png")
generator.generate("2", "avatars/test2.png")
generator.generate("3", "avatars/test3.png")
Replace "Desired Name 1", "test1", "2", "test2", "3", and "test3" with whatever you prefer.
Don't forget to extract the file into a folder on your desktop! Also, make sure to install Pillow (run `pip install Pillow`).
Then, run the code. Once the terminal indicates that the process was successful, go to the folder containing the file. You will find a new folder named "avatars" there—that is where your avatars are located.
Enjoy!
